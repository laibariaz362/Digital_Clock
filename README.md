# Digital Clock

A modern and responsive Digital Clock built using HTML, CSS, and JavaScript.

The clock displays the current time, date, greeting based on the time of day, and motivational quotes that change automatically.

##  Features

- Live digital clock
- Current date and day
- Dynamic greeting
  - Good Morning ☀️
  - Good Afternoon 🌞
  - Good Evening 🌙
- Rotating motivational quotes
- Modern neon-style design

- Real-time updates using JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts Practiced

- Date Object
- DOM Manipulation
- Functions
- Arrays
- Conditional Statements
- `setInterval()`
- `textContent`
- String Methods
- `padStart()`
